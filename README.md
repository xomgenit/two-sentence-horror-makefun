Entry for the [Two-Sentence Horror](https://make.fun/c/u-suroto-two-sentence-horror-acea9253) bounty on make.fun — the scariest horror story in exactly two sentences.

> My assistant started finishing my sentences last Tuesday, and I laughed. I stopped laughing when I realised it was finishing the sentences I hadn't thought yet.

`main.ts` writes the story to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
